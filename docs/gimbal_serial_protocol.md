# 视觉 — 电控串口通信协议说明

> 适用代码：`io/gimbal/gimbal.hpp`、`io/gimbal/gimbal.cpp`、`tools/crc.cpp`、`src/standard_mpc.cpp`
> 用途：视觉上位机（Orin NX / NUC）与下位机（MCU）之间的自瞄/打符双向串口通信。

---

## 1. 物理层与通用约定

- **物理接口**：USB-CDC 虚拟串口（上位机默认设备路径 `/dev/gimbal`，8N1）。
  - USB-CDC 忽略波特率；若改走硬件 UART/TTL，请提前告知以便在上位机显式设置波特率。
- **字节序与对齐**：全部为 **小端（Little-Endian）**，结构体采用 `__attribute__((packed))` 无填充字节，浮点数为 IEEE-754 单精度 `float`（4 字节）。
- **帧头**：固定 2 字节 `'S', 'P'`（十六进制 `0x53, 0x50`）。
- **校验方式（CRC16）**：RM 裁判系统同款 CRC16（初值 `0xFFFF`，反射多项式 `0x8408`，与 DJI 官方 `Get_CRC16_Check_Sum` 完全一致）。
  - 校验范围：从帧头 `'S'` 开始到 `crc16` 之前的全部字节；
  - 存放方式：小端 2 字节置于帧尾。
- **推荐收发频率**：
  - **电控 → 视觉**：建议 **500 ~ 1000 Hz**（上位机用四元数队列按相机曝光时间戳做 SLERP 插值，频率越高时间同步越准）。
  - **视觉 → 电控**：**100 Hz**（MPC 规划周期 10 ms）。

## 2. 坐标系与符号约定（联调必看）

视觉系统采用 **右手坐标系（ENU / ROS 风格）**：

- **`+X`**：枪管/云台正前方
- **`+Y`**：云台正左方
- **`+Z`**：竖直向上

| 物理量 | 单位 | 正方向与范围定义 | 注意事项 |
|---|---|---|---|
| **四元数 `q[4]`** | 无量纲 | 顺序 **`[w, x, y, z]`**，表示 IMU 机体到惯性世界系的右手系旋转 `R_imu2world` | 模长需归一化；云台水平朝前静止时约 `[1, 0, 0, 0]` |
| **`yaw` / `yaw_vel` / `yaw_acc`** | `rad`, `rad/s`, `rad/s²` | 绕 `+Z` 轴，**向左转为正**（俯视逆时针为正） | **惯性世界系（IMU 系）绝对角**，不要发相对底盘编码器角；建议归一化到 `(-π, π]` |
| **`pitch` / `pitch_vel` / `pitch_acc`** | `rad`, `rad/s`, `rad/s²` | **向上（抬头）为正、向下（低头）为负**；范围 **`+30°` 到 `-20°`**（`+0.5236` 到 `-0.3491 rad`） | 上下行 `pitch` 及其速度/加速度前馈均采用**抬头为正**；上位机在 `io::Gimbal` 串口边界自动与内部右手系换算并做 `[-20°, +30°]` 软限位 |
| **`bullet_speed`** | `m/s` | 正值（如 `23.5`） | 裁判系统实测弹速；未发弹时可填标称初速（如 `23.0`） |
| **`bullet_count`** | `uint16` | 每实际发射 1 发自增 1（允许自然回绕） | 用于上位机视觉弹道闭环（`AimCorrector`）对齐出膛时刻 |

> **说明**：若下位机 IMU 芯片安装方向与云台系存在固定旋转（如贴片朝向不同），只需保证四元数本身满足右手系，上位机可通过 YAML 中的 `R_gimbal2imubody` 矩阵适配；但 `yaw`、`pitch` 及其速度/加速度必须已换算到上述云台世界系方向。

## 3. 电控 → 视觉：`GimbalToVision`（共 43 字节）

| 字节偏移 | 长度 | 类型 | 字段名 | 说明 |
|---|---|---|---|---|
| 0..1 | 2 | `uint8_t[2]` | `head` | 帧头，固定 `{'S', 'P'}`（`0x53, 0x50`） |
| 2 | 1 | `uint8_t` | `mode` | `0`: 空闲（IDLE），`1`: 自瞄（AUTO_AIM），`2`: 小符（SMALL_BUFF），`3`: 大符（BIG_BUFF） |
| 3..18 | 16 | `float[4]` | `q` | IMU 四元数，顺序 **`w, x, y, z`** |
| 19..22 | 4 | `float` | `yaw` | 当前云台世界系 yaw（`rad`，左正右负） |
| 23..26 | 4 | `float` | `yaw_vel` | 当前云台世界系 yaw 角速度（`rad/s`，左正右负） |
| 27..30 | 4 | `float` | `pitch` | 当前云台世界系 pitch（`rad`，**抬头正、低头负**，范围 `-20° ~ +30°`） |
| 31..34 | 4 | `float` | `pitch_vel` | 当前云台世界系 pitch 角速度（`rad/s`，**抬头正、低头负**） |
| 35..38 | 4 | `float` | `bullet_speed` | 当前弹速（`m/s`） |
| 39..40 | 2 | `uint16_t` | `bullet_count` | 累计发弹次数（每发射 1 发加 1） |
| 41..42 | 2 | `uint16_t` | `crc16` | 对前 41 字节计算的 CRC16（小端） |

### C/C++ 结构体定义

```c
struct __attribute__((packed)) GimbalToVision
{
  uint8_t head[2];        // {'S', 'P'}
  uint8_t mode;           // 0: IDLE, 1: AUTO_AIM, 2: SMALL_BUFF, 3: BIG_BUFF
  float q[4];             // w, x, y, z
  float yaw;              // rad, 左正右负
  float yaw_vel;          // rad/s, 左正右负
  float pitch;            // rad, 抬头正、低头负（范围 -20° ~ +30°）
  float pitch_vel;        // rad/s, 抬头正、低头负
  float bullet_speed;     // m/s
  uint16_t bullet_count;  // 累计发弹数
  uint16_t crc16;         // 前 41 字节 CRC16
};
```

## 4. 视觉 → 电控：`VisionToGimbal`（共 29 字节）

| 字节偏移 | 长度 | 类型 | 字段名 | 说明 |
|---|---|---|---|---|
| 0..1 | 2 | `uint8_t[2]` | `head` | 帧头，固定 `{'S', 'P'}`（`0x53, 0x50`） |
| 2 | 1 | `uint8_t` | `mode` | `0`: 不控制，云台由操作手接管；`1`: 视觉控云台、不开火；`2`: 视觉控云台且请求开火 |
| 3..6 | 4 | `float` | `yaw` | 目标世界系 yaw（`rad`，左正右负） |
| 7..10 | 4 | `float` | `yaw_vel` | yaw 速度前馈（`rad/s`） |
| 11..14 | 4 | `float` | `yaw_acc` | yaw 加速度前馈（`rad/s²`） |
| 15..18 | 4 | `float` | `pitch` | 目标世界系 pitch（`rad`，**抬头正、低头负**，范围 `-20° ~ +30°`） |
| 19..22 | 4 | `float` | `pitch_vel` | pitch 速度前馈（`rad/s`，**抬头正、低头负**） |
| 23..26 | 4 | `float` | `pitch_acc` | pitch 加速度前馈（`rad/s²`，**抬头正、低头负**） |
| 27..28 | 2 | `uint16_t` | `crc16` | 对前 27 字节计算的 CRC16（小端） |

### C/C++ 结构体定义

```c
struct __attribute__((packed)) VisionToGimbal
{
  uint8_t head[2];   // {'S', 'P'}
  uint8_t mode;      // 0: 不控制, 1: 控云台不开火, 2: 控云台且开火
  float yaw;         // rad, 左正右负
  float yaw_vel;     // rad/s
  float yaw_acc;     // rad/s²
  float pitch;       // rad, 抬头正、低头负（范围 -20° ~ +30°）
  float pitch_vel;   // rad/s, 抬头正、低头负
  float pitch_acc;   // rad/s², 抬头正、低头负
  uint16_t crc16;    // 前 27 字节 CRC16
};
```

## 5. 上电联调核对清单

1. **静置核对**：云台水平朝前时 `q ≈ [1, 0, 0, 0]`，`pitch ≈ 0`，`yaw_vel ≈ 0`，`pitch_vel ≈ 0`。
2. **手掰云台核对方向**：
   - 手动**向左**转云台：`yaw` 增大、`yaw_vel > 0`，`q` 绕 `+Z` 正转；
   - 手动**向上抬头**：`pitch` 增大（变正，上限约 `+30°`）、`pitch_vel > 0`；向下低头 `pitch` 减小（变负，下限约 `-20°`）。
3. **发弹计数核对**：每打出一发弹丸 `bullet_count` 稳定 `+1`，`bullet_speed` 及时更新。
4. **前馈接入建议**：
   - 串级 PID 推荐将 `yaw_vel / pitch_vel` 接入速度环前馈，`yaw_acc / pitch_acc` 接入电流/力矩前馈；
   - 若电控暂未接前馈，仅用 `yaw / pitch` 位置设定也能跑通，后续通过上位机 `real_gimbal_sysid` 扫频辨识实车闭环传递函数即可匹配 MPC 规划器。
5. **安全保护**：当 `mode == 0` 或串口超时断连（建议 > 200 ms）时，电控应立即退出视觉控制并交还操作手，同时停止拨弹。

## 6. 后续扩展预留：跑打底盘速度（待与电控对齐）

- **当前版本（43 字节帧不变）**：
  - 上位机已直接从 `GimbalToVision.q[4]` 实时提取云台/机身 **`roll`** 倾角（写入 `io::GimbalState::roll`），并送入 `Planner::SelfMotion` 补偿坡面/侧倾下的炮口 3D 偏移与静态零偏旋转，**无需修改现有串口帧**。
  - `io::GimbalState` 已预留世界系底盘线速度字段 `vx / vy / vz`（`m/s`，默认 `0`），并已打通至 `Tracker`、`Target::predict`、`Planner` 与 `Trajectory3D`。
- **后续接入底盘速度建议方案**（二选一，确定后同步更新结构体与 `io/gimbal/gimbal.cpp`）：
  1. **推荐（世界系速度，+12 B，总长 55 B）**：在 `bullet_count` 后、`crc16` 前追加 `float vx, vy, vz`（单位 `m/s`，与 `yaw` 同一个惯性世界系 ENU，`+X` 朝向 `yaw=0`、`+Y` 朝向 `yaw=+90°`、`+Z` 向上）。
  2. **备选（云台/底盘体轴速度，+8 B，总长 51 B）**：下发云台体轴前向/左向速度 `v_fwd, v_left`（`m/s`），由上位机用当前 `yaw` 旋转到世界系（需注明是相对云台系还是底盘系，若为底盘系还需额外提供云台相对底盘编码器角 `yaw_rel`）。
- **低通滤波与延迟要求**：底盘里程计/轮速解算建议在 MCU 侧做适度低通（截止频率 ~10–15 Hz），避免轮子打滑尖峰直接注入视觉 EKF 预测。

## 7. 后续扩展预留：2027 概率火控与射频协同（待与电控对齐）

职责划分：**枪口热量硬保护、剩弹与堵弹处理留在电控（1 kHz 本地闭环）**；**视觉输出校准命中概率驱动的开火窗口与建议射频（含单块装甲板防吞弹与换板接发）**。视觉侧 `Planner` 与 `RuntimeParams` 已就绪，串口侧建议扩展 2 字节（上行 1 B + 下行 1 B）：

### 7.1 电控 → 视觉（建议新增 `uint8_t fire_ctrl_state`，+1 B）

| Bit 位 | 字段名 | 编码定义 | 说明 |
|---|---|---|---|
| `bit 0..1` | `fire_mode` | `0=Normal`、`1=ForceBurst`、`2=Eco` | **强制爆发 (`ForceBurst`)**：操作手按住爆发键，**或**雷达/裁判系统判敌方残血触发；视觉阈值 `-0.15` 并忽略保守降频，电控同步放宽本地热量余量 |
| `bit 2..3` | `level_phase` | `0=Unknown`、`1=Leveling`、`2=Capped` | 步兵自身等级阶段：未满级发育期 `-0.08` 加速吃 `80~120 XP/发`；达等级上限（5 级封顶前 / 10 级满级）`+0.05` 收紧省弹保 $\eta$ |
| `bit 4..7` | `heat_ratio_q4` | `0..15` 映射至 `0.0..1.0` | 当前枪口热量占比（`heat / heat_limit`）；非强制爆发模式下 `> 0.70` 时视觉平滑抬高阈值（至多 `+0.08`）并向低频收敛，将最后热量留给 `p_hit > 90%` 必中窗口 |

### 7.2 视觉 → 电控（建议新增 `uint8_t fire_rate_hz`，+1 B）

- **字段含义**：单位 `Hz`，`0` 表示停火，`1..25` 表示视觉建议的拨弹频率。
- **防吞弹与换板红利**：2027 规则 17mm 单块装甲模块最小检测间隔为 `50 ms`（理论上限 `20 Hz`），工程默认上限 `max_fire_rate_hz = 10 Hz`（可调至 `10~15 Hz`）；当视觉判定切换至新装甲板（`plan.fire_plate_id` 变化）或处于 `ForceBurst` 时，立即输出上限射频，避免同板吞弹并吃满换板独立计时红利。
- **电控执行原则**：电控以 `min(视觉 fire_rate_hz, 本地热量允许最大射频)` 驱动拨弹盘，永远以本地热量硬保护为最高优先级。
