# 实车自瞄联调与跟随曲线优化记录（2026-11-27）

> 本文记录轮腿云台（STM32F407）与上位机（Orin NX `yunqian_vision`）首次全链路闭环自瞄联调、排障、观测解耦与跟随曲线精调的完整流程与定量数据，可作为后续新车型/换结构后的标准调参 SOP。

## 1. 测试平台与目标

- **下位机（电控）**：STM32F407，工程 `/home/scj/桌面/rm2027/27-wheel-leg-wbc-gimbal`，500 Hz LQR + 前馈，USB-CDC `/dev/ttyACM0`（1000 Hz 上行，`0483:00ca`），CMSIS-DAP 烧录与实时采样。
- **上位机（视觉）**：Jetson Orin NX（`192.168.55.1`，`~/yunqian_vision`），海康 `MV-CS016-10UC` 相机 + TensorRT `yolov5_nms.fp16.engine`（100 fps），运行 `standard_mpc --no-fire --web --port=8090 configs/standard3.yaml`。
- **测试目标**：正前方约 `2.1 ~ 2.3 m` 处旋转红色小陀螺装甲板（转速 `3.5 ~ 4.5 rad/s`，半径 `r ≈ 0.30 m`）。
- **调优目标**：消除观测锯齿波浪与 EKF 发散，使实车跟随曲线逼近同济平滑 S 曲线效果（换板无过冲振铃、线性段零滞后贴紧目标角）。

## 3. 基础链路与系统辨识（SysID）

1. **链路核验**：确认相机与 TensorRT 推理稳定 `100.0 fps`，串口上行 `1000.7 Hz` 零 CRC 错误，下行控制帧正常。
2. **端到端系统辨识**：使用 `real_gimbal_sysid` + `fit_gimbal_tf.py`（100 Hz，带速度/加速度前馈）辨识云台闭环动态特性：
   - **Yaw**：`wn = 33.21 rad/s`，`zeta = 0.538`，`tau_d = 15 ms`，`a_max = 226.5 rad/s²`，阶跃超调 `48.6%`，在 `4.7 Hz` 处存在 `+2.24 dB` 谐振峰；
   - **Pitch**：`wn = 45.00 rad/s`，`zeta = 0.920`，`tau_d = 15 ms`，`a_max = 114.0 rad/s²`。
3. **结论**：因下位机已带速度/加速度前馈，上位机 `gimbal_yaw_wn` / `gimbal_pitch_wn` 保持 `0.0`（避免植物逆 MPC 与下位机前馈叠加放大过冲）。

## 4. 观测层排障：用排除法定位“动云台锯齿变歪”与 EKF 发散

初始闭环自瞄时发现：`ref_yaw` 目标锯齿明显发波浪（单板线性度 RMS `0.78° ~ 0.87°`），`target_center.y` 抖动 `±2.0 cm`，`w` 波动 `±0.36 rad/s`，且伴随偶发 `Target diverged`。按以下 4 步逐一排除：

### 步骤 4.1 降低旋转运动模糊与短丢检
- 原配置 `exposure_ms: 4.0`、`threshold: 150` 下短丢检率 `15.5%`；
- 调整为 `exposure_ms: 3.0`、`threshold: 110`，丢检率降至 `7% ~ 10%`。

### 步骤 4.2 无标定板自动慢摆标定（排除内参/手眼外参）
- 停转前方红板作为静止靶标，通过脚本控制云台做 10 s 低速正弦扫动（`0.25 Hz` Yaw `±9°`、`0.35 Hz` Pitch `±5°`），采得 `914` 帧检测与 `10057` 帧编码器姿态做线性与非线性重投影拟合：
  - `d(cam_yaw) / d(gimbal_yaw) = -0.9983`（误差 `0.17%`）
  - `d(cam_pit) / d(gimbal_pit) = -1.0009`（误差 `0.09%`）
  - `cam_roll = +0.16°`，`t_camera2gimbal.x = +0.005 m`
- **结论**：相机内参（`fx=1809, fy=1806`）与水平安装外参精度极高，**排除了内参和手眼平移视差耦合**。

### 步骤 4.3 修复规划线程掉拍 & 增加 `IDLE` 识别预测预览
- 在 `src/standard_mpc.cpp` 中：
  1. 将 `plan_thread` 的 `sleep_for(10ms)` 改为严格 100 Hz `sleep_until(next_tick)`，消除每 6~8 帧出现一次 20 ms 重复指令台阶（重复帧率 `0/401 = 0.0%`）；
  2. 开启 `IDLE` 模式持续运行检测、EKF 追踪与 MPC 规划（用于 WebViewer 预览），仅在串口下发处拦截为 `control = false`（电控不跟随）。

### 步骤 4.4 `IDLE` 静止 vs `AUTO_AIM` 运动对照（锁定根本原因）
- **`IDLE`（云台静止）实测 4 s**：
  - 单板锯齿线性度 RMS：**`0.186°`**（接近仿真标准锯齿）
  - 中心 Y 抖动：`tc_y std = 0.37 cm`；转速估计：`w = -3.96 ± 0.07 rad/s`
  - 二阶差分噪声：`0.024°`；`r = 0.301, l = -0.001, nis = 0.1 ~ 0.8`（0 发散）
- **`AUTO_AIM`（云台运动）同步抓取 STM32 编码器 vs 板载 IMU**：
  - 电机编码器摆幅 `10.59°`，IMU 世界航向摆幅 `12.89°`；
  - 两者差值 **`RMS = 0.89°`、最大 `1.83°`**，且每次换板施加 `±1.1 Nm` 力矩时 `IMU - Encoder` 严格同相跳变 `±0.85°`。
- **根因实锤**：底盘处于 `CHASSIS_ZERO_FORCE` 无力状态，云台加减速反作用力矩引起底盘/支架 `±0.8°` 反作用晃动；**电机编码器只测云台相对底盘、看不到底盘晃动**，而相机看到的是真实世界偏转，导致 `0.89°` 的反作用晃动被原封不动注入 EKF，把 `0.186°` 的标准锯齿拉歪成了 `0.874°`。

## 5. 按实测 IMU 朝向切回世界系 Yaw

由于此前因机械改动旋转了 IMU 安装位置，切回前先通过 EmberProbe 实测静止加速度矢量：
- 实测 `INS.Accel = [-0.32, +9.77, -0.07] m/s²` → 确认 **`+Y_imu` 轴竖直向上（对应世界系 `+Z_up`）**；
- 由右手定则及实测相关性（`corr = +0.9583, lag = 0 ms`）确认：
  - 世界系航向角 = `INS.Yaw`（左正右负，与视觉约定同号）；
  - 世界系航向角速度 = `INS.Gyro[1]`（而非 `INS.Gyro[2]`）。

在 `application/gimbal/gimbal.c` 中做最小安全改动：
1. **视觉 Yaw 反馈 & 误差基准**切回 `INS.Yaw` 与 `INS.Gyro[1]`；
2. **Pitch 反馈与限位**继续使用电机编码器（不受 IMU 侧装影响，跟踪误差稳定 `0.40°`）；
3. **Yaw `±30°` 机械软限位**继续基于开机编码器原点 `yaw_origin_rad`；
4. 上位机保持 `use_euler_q: true`（由串口 `yaw` [IMU 世界系] + `pitch` [编码器] 构造四元数）。

**切回后立竿见影**：锯齿线性度从 `0.874°` 骤降至 **`0.339°`**，执行器误差从 `1.77°` 降至 **`1.06°`**，端到端相位对齐 **`+0.0 ms`**，EKF 彻底零发散。

## 6. 控制与规划精调（对齐同济平滑曲线）

### 6.1 避坑：切忌盲目拉高下位机高频速度增益
- 曾尝试将 Yaw LQR 速度增益 `K_vel` 从 `0.96f` 提至 `1.35f / 1.60f`，虽然低频超调减小，但推高了高频增益并激起云台 **55 Hz 柔性扭振自激异响（`±6 Nm` 满力矩振荡）**；
- 立刻恢复原装 Bode 校核值 **`K_vel = 0.96f`** 后异响彻底消失。

### 6.2 压制换板后 `6.25 Hz` 积分振铃（降 `K_i`）
- 切回 IMU 后，10 ms 逐帧波形显示单板内 `ref_yaw` 极直（每 10 ms 稳定 `-0.33° ± 0.02°`），但换板后云台存在 2~3 次 `6.25 Hz` 振铃（`+1.94° → -1.40° → +0.90°`）；
- 原因是原 Yaw LQR 积分增益 `K_i = 120.0f` 在 5~6 Hz 处消耗了约 `25°` 相位裕度；
- 将 `K_i` 下调至 **`35.0f`**（不动高频 `K_vel = 0.96f`），增加低频相位裕度且完全不触碰 55 Hz 模态，执行器误差进一步降至 **`0.95°`**（`r = 0.939`）。

### 6.3 相机时间延迟精确寻优
- 扫描不同 `L` 下重建世界角 `gimbal_yaw(t - L) + cam_du(t)` 的二阶差分 RMS：
  - `L = 0 ms`: `0.1023°` | `L = 2 ms`: `0.0774°` | **`L = 4 ms`: `0.0673°`（最优）** | `L = 6 ms`: `0.0779°` | `L = 10 ms`: `0.1334°`
- 确定 **`camera_latency_ms: 4.0`**（实测降至 `2.0 ms` 时会因高速时间戳错位拉爆 EKF `nis` 导致发散）。

### 6.4 对齐同济平滑 S 曲线（收柔 MPC 规划）
- 对照同济实车曲线，其核心特征是底部 `/plan_yaw_acc` 为**峰值 `±35 rad/s²` 的圆润钟形 S 曲线**，不顶死加速度限幅，从而让云台速度/位置几乎 1:1 贴死规划轨迹、线性段紧贴目标角；
- 在 `configs/standard3.yaml` 中收敛规划参数：
  - `max_yaw_acc: 60.0 → 45.0`
  - `Q_yaw: [4.0e6, 0] → [2.0e6, 0]`
  - `high_speed_delay_time / low_speed_delay_time: 0.005 → 0.002`

## 9. 可复用实车调参 SOP 摘要

1. **先静止看观测（`IDLE`）**：确认静止下锯齿线性度 `< 0.25°`、丢检率 `< 10%`、EKF `nis < 2`。
2. **再动云台查解耦（`AUTO_AIM`）**：若静止规整、一动就歪，优先查两项——① **世界系一致性**（切忌用电机编码器代替 IMU 当世界系 Yaw）；② **时间戳对齐**（扫 `L` 最小化 `gimbal(t-L) + du(t)` 二阶差分，实测约 `4.0 ms`）。
3. **最后调跟随曲线**：下位机优先用低频 `K_i` 释放 5~6 Hz 相位裕度（慎动高频 `K_vel` 防激起机械扭振）；上位机压柔 `max_yaw_acc` 和 `Q_yaw` 让规划加速度呈圆润钟形 S 曲线，最后用 `delay_time` 把线性段相位对齐到 `0 ms`。
